                                                 Projet-Exoplan-tes
# Description
Ce projet analyse des données d’exoplanètes pour étudier leurs caractéristiques (taille, masse, distance à leur étoile, etc.).  
Le but est de pratiquer le traitement de données avec Python et Jupyter Notebook.
## Prérequis
- Python (version 3.x)
- Jupyter Notebook
### Dépendances (bibliothèques Python)
- numpy
- pandas
- matplotlib
*Explication*
- **Prérequis / Dépendances** : ce sont les outils que l’utilisateur doit avoir installés pour pouvoir utiliser mon projet.
